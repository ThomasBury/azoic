# Azoic

Azoic is a scikit-learn-compatible toolkit for non-life technical tariff and pure-premium modelling. It keeps the actuarial essentials explicit: exposure weighting, ranking and calibration diagnostics, reproducible model comparisons, and exportable multiplicative tariffs.

Start with [installation](getting-started/installation.md), then fit a [first model](getting-started/first-model.md).
